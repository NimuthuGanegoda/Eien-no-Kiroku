# 💠 Eien-no-Kiroku (永遠の記録) 💠

> "Eternity is not a destination, but the path we pave with every record."

## 🌐 [VIEW LIVE DASHBOARD HERE](https://nimuthuganegoda.github.io/Eien-no-Kiroku/) 🌐

[![Eien-no-Kiroku CI](https://github.com/NimuthuGanegoda/Eien-no-Kiroku/actions/workflows/ci.yml/badge.svg)](https://github.com/NimuthuGanegoda/Eien-no-Kiroku/actions/workflows/ci.yml)

**Eien-no-Kiroku** (Eternal Record) is a next-generation, AI-powered referencing tool designed to bring absolute order to the chaos of academic research. Built for the elite, it aims to surpass tools like Mendeley and MyBib by providing **100% accurate**, fully automated metadata detection. ⚡🌸

---

## ✨ Key Features ✨

*   **🔍 Smart Detection:** Drop a DOI, ISBN, or URL, and watch as the system extracts perfect metadata instantly.
*   **📄 PDF Alchemy:** Advanced parsing using **GROBID** to identify authors, titles, and citations from even the messiest papers.
*   **🤖 AI Verification:** Every record is cross-referenced by LLMs to ensure the data is beyond reproach.
*   **📜 Multi-Format Support:** Export to BibTeX, APA, MLA, and more with zero effort.
*   **🏛️ Eternal Storage:** Your references are managed with the weight of eternity behind them.

---

## 🛠️ Tech Stack 🛠️

*   **Backend:** [FastAPI](https://fastapi.tiangolo.com/) (Python) 🐍 - High-performance, asynchronous power.
*   **Frontend:** [React](https://reactjs.org/) + [TypeScript](https://www.typescriptlang.org/) + [Vite](https://vitejs.dev/) ⚛️ - A lean, responsive, and beautiful interface.
*   **Automation:** [GitHub Actions](https://github.com/features/actions) ⚙️ - Automated CI/CD for a self-sustaining ecosystem.
*   **Intelligence:** Crossref API, Google Books, and AI-driven validation engines. 🧠

## 🚀 The Path to Eternity 🚀

### 🏗️ Local Setup

1.  **Clone the Soul:**
    ```bash
    git clone https://github.com/NimuthuGanegoda/Eien-no-Kiroku.git
    cd Eien-no-Kiroku
    ```

2.  **Ignite the Backend:**
    ```bash
    cd backend
    python3 -m venv venv
    source venv/bin/activate
    pip install -r requirements.txt
    python main.py
    ```

3.  **Awaken the Frontend:**
    ```bash
    cd frontend
    npm install
    npm run dev
    ```
